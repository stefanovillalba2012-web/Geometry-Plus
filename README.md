# Geometry Plus+ (por Bosked)

Mod para Geode / Geometry Dash 2.2074.

## Contenido
- 10 portales de vehículo (variantes de física)
- 10 vehículos originales (IDs 4501-4510): Cohete, Péndulo, Resorte, Planeador,
  Imán, Dasher, Globo, Rebotador, Serpiente, Turbina
- 8 velocidades nuevas, 3 tamaños, 2 portales de cámara libre
- 3 vehículos de plataforma

## Compilar
1. Instala el Geode SDK y la CLI (`geode sdk install`).
2. En esta carpeta: `geode build` -> te genera el `.geode`.
3. Cópialo a la carpeta `geode/mods` del juego.

Sin PC: sube la carpeta a un repo de GitHub y corre la acción "Build Geometry Plus+";
al terminar descargas el `.geode` desde Artifacts.
